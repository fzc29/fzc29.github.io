In this section, we explored 2D convolution, where I slid a filter across an image, multiplying and summing overlapping pixel values between the image and filter to produce a new output image. Looking at the 3 chosen filters:

1.Box -> blur the image since it averages the neighboring pixels (compared to image on the right, I am using 9x9 box filter and it should be normalized)
2.D_X -> the first finite difference operator that highlights any vertical edges
3.D_Y -> the second finite difference operator that highlights horizontal edges

Using a black and white picture of myself, I computed 3 output forms using the above filters and code below.

Here we fliped the kernel and applied the dot product by sliding the filter across the image. I chose to pad the images so that the output after convolution ends up being the same size as the initial image. Any padding added were filled with zero values. So the edges are assumed to be black and will darken the resulting boundaries of the image.

Finally, comparing the outputs to scipy.signal.convolve2d, I was able to confirm the accuracy of my code. However, the runtime showed an interesting result. My convolve using 4 loops ended up being faster than my 2 loop when using the finite difference operators. However, for the box filter, the 2 loops performed significantly better.

          def convolve_4loop(image, kernel):
            """
            Convolution with 4 loops 
    
            Input: 
            Image = 2d numpy array (gray scale)
            Kernel = 2d nump array (assume all odd dimensions)
    
            Output:
            Convoluted kernel with image using "same" mode padding of 0's 
            """
            
            m_rows, m_cols = image.shape
            k_rows, k_cols = kernel.shape
    
            padding_td = (k_rows - 1) // 2
            padding_lr = (k_cols - 1) // 2
    
            output = np.zeros(image.shape, dtype=np.float64)
    
            # flip kernel twice to reverse it 
            kernel = np.flip(kernel)
    
            # pad image (same)
            image = np.pad(image, ((padding_td, padding_td), (padding_lr, padding_lr)), mode='constant', constant_values=0)
    
            # convolve
            for i in range(m_rows):
                for j in range(m_cols):
                    pixel = 0
                    for row in range(k_rows):
                        for col in range(k_cols): 
                            pixel += image[i+row][j+col] * kernel[row][col]
                    output[i][j] = pixel                 
            
            return output
    
        def convolve_2loop(image, kernel):
            """
            Same as above with only 2 loops 
            """
            m_rows, m_cols = image.shape
            k_rows, k_cols = kernel.shape
    
            padding_td = (k_rows - 1) // 2
            padding_lr = (k_cols - 1) // 2
    
            output = np.zeros(image.shape, dtype=np.float64)
    
            # flip kernel twice to reverse it 
            kernel = np.flip(kernel)
    
            # pad image (same)
            image = np.pad(image, ((padding_td, padding_td), (padding_lr, padding_lr)), mode='constant', constant_values=0)
    
            # using np.sum -> already vectorized function 
            for i in range(m_rows):
                for j in range(m_cols):
                    pixel = np.sum(kernel * image[i: i + k_rows, j: j + k_cols])
                    output[i][j] = pixel
            return output

Part 2: Fun with Frequencies!

Part 2.1: Image "Sharpening"

In this section, we will be utilizing the Gaussian filter to blur and sharpen. Once we apply the Gaussian filter, we are left with the lower frequency portion of the image, which would in turn make the image more blurry. But we can use this to our advantage by then subtracting that lower frequency from our original image, so we are only left with the high frequency portions. Having more high frequency parts of the image makes it appear sharper.

Below shows the progression of increasing sharpening using the unsharp mask filter, first on the Taj Mahal, then on a really nice matcha dessert I had recently.

Part 2.2: Hybrid Images

The goal in this part of the project is to create hybrid images. These are static images that change to the viewer due to the viewing distance. This phenomenon is possible due to human's perception of frequency at different distances. High frequency data tends to dominate our senses when it is present, so when you stand close to the image, then you see and focus on the image displayed with high frequency, but when you are far away, low frequency dominates, since that is all that can be seen. As such, by blending two images with different frequencies, you will focus or interpret different images at different distances.

For this above hybrid images, I conducted a Fourier Analysis. First looking at the sigma values, a greater sigma value means more blurring happens, so more high frequency details will be eliminated. Then for a smaller sigma, I am getting a larger range of the lower frequencies, where when I subtract from the original image, then only the very top portion (higher frequencies) are left. I used some experimentation to pick out sigma values of 15 and 7. It was the best balance where I could see both clearly at their corresponding distances.

I did expect the FFT representations of both my input images to be similar since they are in itself very similar images, and similar art style in terms of the angle and composition of the strokes, especially for the hair portion.
