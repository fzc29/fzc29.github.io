Part A-1 Forward Process

We aim implement custom sampling loops using pretrained Deep Floyd models. These diffusion models work by progressively adding more noise to clean images until it is basically pure noise, then it reverses the process. The model then goes backwards, predicting the noise at each timestep to remove the predicted noise to reconstruct a clean image. To generate an image, we can start with pure noise and iteratively denoise till we reach a clean image.

In this forwarding process, we are adding noise to the image at each timestep using the given formula. At each timestep, we create a noisy image x_t by taking the weighted combination of the original image and some noise determined by alpha_cumprod coefficient. The precision by which we are adding the noise allows for an reverse process. In this formula, notice how we are keeping the variance constant and ensure stability in the system.

Part A-4 Iterative Denoising

In this section, we want to further improve upon the onestep denoising method from above. While stage_1.unet works great, its effectiveness goes down with great timesteps and more noise. Diffusion models are meant to denoise iteratively, but that would take a long time. So instead, we will skip steps. We don't need a perfectly precise denoising schedule, rather just the right direction, while keeping all the information we need, preventing overguessing by the model.

This is likely due to the fact that when we train, we try to match different noise inputs to the same output, causing an overgeneralization in an effort to match input to output. In this case, the model output seems to be an aggregation of all the digits (or an average) so to minimize total loss, since theoretically a noise input can be mapped to any digit.
